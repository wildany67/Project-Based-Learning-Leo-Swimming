# Folder assets-source

Tempat **file asli / resolusi tinggi**. Folder ini **tidak diakses website**.
Foto yang sudah dikompres dan siap tayang dipindah ke `public/images/`.

| Folder | Isi |
| --- | --- |
| `figma-export/` | Hasil ekspor langsung dari Figma (PNG 2x, SVG) |
| `foto-asli/` | Foto dari kamera / HP sebelum dikompres |
| `logo-asli/` | Logo versi asli (AI, PSD, SVG, PNG besar) |

Alur kerja foto: simpan asli di sini → kompres (mis. di squoosh.app) → taruh hasilnya di `public/images/...`.
